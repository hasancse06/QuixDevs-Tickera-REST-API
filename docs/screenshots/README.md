# Historical source-project screenshots

These images were copied unchanged from the original plugin. They record earlier source-project verification and are not new screenshots of the GitHub distribution. Current distribution verification uses real Tickera admin-field renderers and is reported in release-readiness-report.md.


Screenshots show disposable test data, captured through the native Codex browser:

- `event-editor.png`: REST-created event's actual Tickera date metabox, WordPress 6.8.3 / Tickera 3.6.0.8.
- `ticket-editor.png`: REST-created ticket type in Tickera's native editor, WordPress 6.8.3 / Tickera 3.6.0.8. The rendered DOM also verified selected parent, price 60.00 and quantity 100 after REST editing; those fields are below the captured mobile viewport.
- `api-information.png`: addon information screen showing enabled API, version, base URL and authentication guidance, WordPress 7.1.3 / Tickera 3.6.0.8.

These are verification images, not fabricated WordPress.org marketing assets. Tickera onboarding notices are upstream UI; the API works independently of completing that onboarding. The information screen appears under Tools when Tickera temporarily hides its normal menu, and under Tickera once that menu is available. No production or user-private records/credentials are displayed.
