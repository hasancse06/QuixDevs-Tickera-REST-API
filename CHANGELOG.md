# Changelog

## 1.0.0

- Initial QuixDevs author-scoped standalone Tickera event/ticket-type REST API.
- Eight GET/POST/PATCH operations with strict object and parent ownership.
- Explicit request/response fields, local dates, decimal prices and quantity semantics.
- Capability-filtered collection totals and service-layer schema validation.
- Serialize related addon writes and recheck authorization before persistence.
- Actual Tickera hooks, fail-closed dependency handling and safe private responses.
- Documentation, security/integration tests, reproducible lightweight ZIP and draft-only release tooling.
- Finalize GitHub installation/download links, tested-version guidance and contributor documentation.
